## 1. 产品概述
GAStech案调查报告是一个基于 NYT (纽约时报) 高级纸质风格的交互式数据叙事（Scrollytelling）网页。
- **视觉风格**：NYT高级纸质风。使用米白/羊皮纸底色（如 `#F9F9F6`），图表采用低饱和度的高级配色（深板岩蓝、暗砖红、鼠尾草绿）。文字排版考究，标题使用优雅的衬线体，正文/图注使用清晰的无衬线体。
- **交互逻辑**：左侧文本滚动触发右侧视图切换。**明确要求：每翻一页（Slide），右侧换一个全新的图表实例**，不要求复杂的图表间形变动画，但图表入场需有优雅的过渡。
- **核心特色**：高度依赖**图上标注（Annotations）**，将数据结论直接写在图表旁，而非隐藏在 Hover 提示框中。

## 2. 页面细节与可视化映射方案

| Slide 章节 | 左侧叙事文本要点 | 右侧可视化图表设计方案 (ECharts / 自定义实现) |
|-----------|-------------|---------------------|
| **Slide 1: 封面** | 抛出悬念：GAStech高管失踪案。署名：wwh。 | **标题视觉图**：大字号的 Serif 标题，深沉的暗灰色调背景（仅此页偏暗），带有老旧档案或打字机质感。 |
| **Slide 2: 概览** | 数据来源：800多篇新闻、海量邮件与档案。 | **精简数据流程图**：静态或微动的连线图，展示三个数据源汇聚成一个“真相”节点。 |
| **Slide 3: 媒体偏见** | 新闻在撒谎吗？官方淡化，小报激化。 | **带注释的散点图 (Annotated Scatter)**：X轴为偏见得分(0-10)，Y轴为发文量。使用不同颜色区分立场。**关键**：在图表极值点直接用引线标注如“Kronos Star: 极度亲政府”。 |
| **Slide 4: 时间线** | 冰冻三尺非一日之寒。商业、环境、对抗升级。 | **棒棒糖多层时间线 (Stepped Lollipop Timeline)**：长X轴为日期，Y轴分为四个水平带（叙事线）。重要事件的节点加大，并直接在节点上方用文字标出事件名称，如“POK抗议爆发”。 |
| **Slide 5: 关系网** | **核心重点：谁和谁利益相关？** | **分层结构关系网 (Hierarchical Force/Tree Graph)**：<br>1. **中心骨架**：GAStech 的三层组织体系（高层 -> 中层 -> 基层），呈现树状或垂直分布，颜色为深板岩蓝。<br>2. **左侧翼**：Kronos 政府（Government），与 GAStech 高层有粗壮的连线。<br>3. **右侧翼**：POK 组织，与 GAStech 基层/环境事件有连线，颜色为暗砖红/鼠尾草绿。<br>4. **标注**：在政府和高管连线处标注“利益勾结”。 |
| **Slide 6: 邮件泄漏**| 他们其实早有预感？安保邮件激增。 | **异常条形图矩阵 (Small Multiples)**：展示1月1日-20日期间的每日邮件量。在1月16日-19日，“Security”主题的柱子标红，并在上方标注大字：“案发前3天，安保邮件激增”。 |
| **Slide 7: 结案** | 结案陈词：这不是偶发袭击，是必然反噬。 | **综合证据链**：静态总结图，或留白展示最终结案文本。 |

## 3. 技术架构
- **前端框架**: React + Vite + Tailwind CSS (用于构建左侧卡片和整体响应式布局)。
- **图表引擎**: Apache ECharts。由于要求图上标注，需重度使用 ECharts 的 `graphic` 组件（用于绘制线条和文字标注）或 `markPoint` / `markLine`。
- **数据流**: 直接读取 `public/data/` 下的 `emails.csv`, `media_stance.csv`, `timeline_master.csv`, `network_nodes.csv` 等。
- **滚动监听**: 使用 `react-scrollama` 监听左侧卡片的 `onStepEnter` 事件，改变当前激活的 `currentStep` 状态，右侧面板根据状态挂载/卸载不同的 Chart 组件。
